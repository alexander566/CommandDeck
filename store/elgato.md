NAME: CommandDeck
SHORT DESCRIPTION (one line):
Run Minecraft commands from a key, straight into the game. No chat window, any server.

DESCRIPTION:
CommandDeck sends Minecraft chat commands from your Stream Deck straight into the game. No chat window opens and nothing is typed for you, so it works mid-fight, mid-build and on any server.

Drag the Command action onto a key, type a command such as /spawn or /home base, join a world and press it. Put several commands on separate lines to run them in order; lines without a / are sent as chat messages. The key title follows the command automatically.

Requires the free CommandDeck mod for Minecraft (Fabric or Quilt, Minecraft 1.14 to 26.x): https://modrinth.com/mod/commanddeck
Servers don't need anything.

Private by design: the mod only listens on your own computer with a fresh secret every launch, and refuses requests from web browsers.
